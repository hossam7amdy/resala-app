# Resala Backend

Resala Backend is the backend of the Resala E-Commerce Website. It is build using Node.js, Express, and PostgreSQL. It is deployed on Heroku.

## Installation

First, clone the repository:

```bash
git clone
```

Then, install the dependencies:

```bash
npm install
```

## Usage

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:5000](http://localhost:5000) with your browser to see the result.
